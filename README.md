# Java Learning and Practice Projects

This repository contains various Java projects and practice programs covering:

- Core Java concepts
- Collections framework
- Object-Oriented Programming
- Interview preparation questions
- Data structures and algorithms

## Project Structure

```
├── src/
│   ├── collections/     - Learning examples for Java Collections (ArrayList, HashMap, etc.)
│   ├── Demo/            - Basic demonstration programs
│   ├── interviewQuestions/  - Interview preparation programs
│   ├── Practise/        - Practice programs and exercises
│   └── NonRepElem.java  - Non-repeating elements program
├── bin/                 - Compiled class files
└── .classpath          - Eclipse classpath configuration
```

## Getting Started

1. Clone the repository
2. Open the project in Eclipse IDE
3. The project is configured as an Eclipse Java project and should load automatically

## Programs Included

### Collections

## Requirements

- Java Development Kit (JDK) 8 or higher
- Eclipse IDE (recommended) or any Java IDE
